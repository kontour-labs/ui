# Changelog

The changelog is part of the documentation:
[`ui-docs/content/changelog.md`](ui-docs/content/changelog.md).

It is published with the rest of the docs:

- on the site, at `https://docs.kontour.io/ui/#/changelog`;
- as Markdown for agents, at `https://docs.kontour.io/ui/md/changelog.md`,
  which `llms.txt` links from its first lines.

Each entry lists what a release changed, newest first. What an upgrade has to
change is under **Breaking**.
